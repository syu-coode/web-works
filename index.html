SKILLS

HTML/CSS

デザインカンプなどをもとに、Webサイトの新規構築・改修を担当してきました。
HTML/CSS、EJS、SCSS、JavaScript/jQueryを使用し、Gulpによる開発環境での経験もあります。
SCSSではネスト、変数、`&`セレクタ、`@mixin`などを活用し、保守性・再利用性を考慮したコーディングを実践。
レスポンシブ対応を前提とした、運用しやすいWebサイト制作を心掛けています。

JavaScript

モーダルウィンドウ、アコーディオン、ページ内スクロール、スクロール連動アニメーションなどの機能を実装。
また、jQueryを活用したスライダー、ハンバーガーメニュー、アコーディオンメニュー、スライドショー、フェードアニメーションなど、Webサイトに求められる一般的なインタラクションの実装を行ってきました。

CMS

WordPress構築では、オリジナルテーマの作成を経験。
ACFやカスタム投稿ページ・カスタムフィールドの作成等を実装。
MovableType、 PowerCMSでは更新/運用、改修を担っていました。

バージョン管理

SVN、Githubを使用してチームでのバージョン管理の経験があります。

Design Soft

Photoshop、Adobe XD、Figmaで作成されたデザインカンプをもとにコーディングが可能。
画像の書き出しやリサイズなど、制作に必要な基本的な画像編集も可能。
